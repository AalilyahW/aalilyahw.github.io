# Project Scope Statement: My Personal Introduction Webpage

## Project Purpose
The purpose of this project is to apply foundational scoping and project management principles to a concrete technical task: building a personal professional introduction webpage. Longterm, this project serves as a practical bridge between project theory and core technical execution. As a future computing professionally, this webpage will establish an initial digital media footprint, showcasing my background in media, public communication, technical operations, and visual design while ensuring an organized approach to asset development.

## Description
This project consists of building a structured, single-page personal introduction website using clean, semantic HTML. The page will feature a primary level-1 heading (`<h1>`) displaying my name, followed by a level-2 subheading (`<h2>`) identifying my academic major and professional interests. Section boundaries or specific content blocks will be clearly organized using three distinct level-3 subheadings (`<h3>`). The core body content will feature at least two distinct paragraphs (`<p>`) detailing my current career trajectory and course goals, an unordered bulleted list (`<ul>`) mapping out at least three distinct creative or technical hobbies, and a functional hyperlink (`<a>`) pointing directly to my professional GitHub profile.

## Desired Results
The project will be considered a success when it has the following criteria:
* **Technical Alignment:** The `index.html` file passes clean validation through the official W3C HTML Validator with zero syntax errors.
* **Rubric Adherence:** All mandatory structural elements (`<h1>`, `<h2>`, `<h3>`, `<p>`, `<ul>`, `<li>`, and `<a>`) are perfectly implemented and rendered accurately across modern browsers.
* **Delivery Excellence:** The final project structure is successfully compiled into a single `.zip` file containing exactly two flawlessly named files (`scope.md` and `index.html`) and submitted before the deadline.

## Exclusions
To maintain strict boundaries and prevent scope creep, this project excludes the following elements from its current lifecycle:
* **Visual Styling:** No CSS stylesheets, inline styles, or presentation framework integrations will be included.
* **Interactivity:** No JavaScript or dynamic client-side scripting will be utilized.
* **Architecture:** The project will remain strictly a single-page document; no multi-page routing or complex site directories will be built.
* **Media Hosting:** No local video or audio rendering assets will be built into the document structure.
